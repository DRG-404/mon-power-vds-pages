Before you download the Job JSON, clean up the job in Katapult. Assume the tracing isn't accurate: the tool only reads what's in Katapult, so every mistake there ends up on the sheet.
  1. Go through every pole in the job, not just the ones with notes.
  2. Move each pole marker onto the pole's shadow in the aerial, so span lengths and directions are right.
  3. Fix the down guy / anchor alignment on each pole.
  4. Check the traces: each wire goes to the right pole, with the right company, wire type and spec (streetlight sizes are often mislabeled).
  5. Then export the Job JSON (Download Manager → Data → Job JSON).
Then click Load Job JSON in step 1 above, or drop the file anywhere on this page. After the make-ready in Katapult, use Load after JSON to re-check every pole. Each pole gets its own column, the same as your Violation Determination sheet. Every pole gets its column when the job loads.
